## 3. 前提条件の確認

新しいセッションで環境を再現する前に、以下を確認してください。

### 3.1 システム情報の確認

```bash
# OS バージョン確認
cat /etc/os-release | grep -E "^(NAME|VERSION)="

# カーネル確認
uname -r

# CPU コア数・メモリ確認
nproc
free -h

# 作業ディレクトリ確認
pwd
```

**期待される出力例（テンプレート）:**

```text
NAME="[OS 名]"
VERSION="[OS バージョン]"
Linux [カーネルバージョン]
[コア数] cores
[メモリ容量] RAM
[プロジェクトルートディレクトリパス]
```

### 3.2 必須ツールの存在確認

```bash
# パッケージマネージャ（例: uv）
which uv && uv --version

# タスクランナー（例: just）
which just && just --version

# その他システムツール（必要に応じて）
which [コマンド1] && echo "[コマンド1] installed"
which [コマンド2] && echo "[コマンド2] installed"
```

ツールが見つからない場合は、セクション 4.1 を参照してインストールしてください。

### 3.3 Git ブランチ・コミット確認

```bash
# 現在のブランチ確認
git branch --show-current

# 最新コミット確認
git log --oneline -1
```

**期待される出力例:**

```text
[作業ブランチ名]
[コミットハッシュ] [コミットメッセージ]
```

## 4. 環境セットアップ手順

### 4.1 システムパッケージの確認／インストール

```bash
# 例: 必要なシステムパッケージのインストール
apt-get update -qq
apt-get install -y -qq [system-package-1] [system-package-2] ...
```

**注意事項例:**

* `[インストールが失敗する既知パッケージがあれば記載]`
* `[該当パッケージがなくても作業継続に支障がない旨など]`

### 4.2 Python 依存パッケージのインストール（最重要）

```bash
# 現在のパッケージ状態確認（必要に応じて）
uv pip list 2>/dev/null | head -20

# 未インストール／エラーの場合の同期
uv sync --no-install-project
```

**インストール対象例（dependencies / dev-dependencies を箇条書き）:**

* dependencies:

  * `[ライブラリ名] - [用途]`
* dev-dependencies:

  * `[ライブラリ名] - [用途]`

**インストール確認例:**

```bash
uv pip list | grep -E "(packageA|packageB|packageC)"
```

### 4.3 特殊な実行環境（例: Xvfb、Docker 等）のセットアップ

```bash
# 例: Xvfb の起動確認と起動
ps aux | grep -E "Xvfb.*:99" | grep -v grep

if ! ps aux | grep -E "Xvfb.*:99" | grep -v grep > /dev/null; then
    echo "Starting Xvfb :99..."
    Xvfb :99 -screen 0 1280x800x24 > /tmp/xvfb.log 2>&1 &
    sleep 2
    echo "Xvfb started"
else
    echo "Xvfb already running"
fi

# 環境変数設定
export DISPLAY=:99
export LIBGL_ALWAYS_SOFTWARE=1
```

必要に応じて Docker コンテナ起動コマンド等をここに追記してください。

### 4.4 環境変数の永続化（任意）

```bash
echo 'export DISPLAY=:99' >> ~/.bashrc
echo 'export LIBGL_ALWAYS_SOFTWARE=1' >> ~/.bashrc
source ~/.bashrc
```

## 5. 動作確認

環境構築後、最低限以下の確認を行ってください。

### 5.1 特殊環境の動作確認（例: Xvfb）

```bash
# テスト用 GUI アプリ起動（例）
DISPLAY=:99 [テストアプリコマンド] &
TEST_PID=$!
sleep 2

# プロセス確認
ps aux | grep [テストアプリ名] | grep -v grep

# スクリーンショット取得（必要なら）
[スクリーンショット取得コマンド]

# 後処理
kill $TEST_PID 2>/dev/null || true
```

### 5.2 Python 依存パッケージ動作確認

```bash
uv run python -c "import [ライブラリA]; print([ライブラリA].__version__)"
uv run python -c "import [ライブラリB]; print([ライブラリB].__version__)"
uv run pytest --version | grep pytest
```

### 5.3 メインフレームワークの最小動作確認

```bash
# 例: GUI フレームワークがヘッドレス環境で動くか確認
DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=1 timeout 5 uv run python -c "
import [メインフレームワーク] as fw
print('framework ok')
"
```

### 5.4 タスクランナー（just 等）の動作確認

```bash
just --list
# 必要に応じて既存レシピを 1 つ試す
# 例: just smoke-test
```

代表的な問題と対処方法を列挙します。
必要に応じてプロジェクト固有の内容を追加してください。

### 問題1: `[コマンド] not found`

**原因例**: インストールされていない、PATH が通っていない
**解決策例**:


**解決策**:


**例・解決策**:

```bash
# DISPLAY 未設定エラー

```

## このドキュメントについて

本ガイドは、新しいセッションや新規参加メンバーが、短時間で同一の開発・実行環境を再現し、スムーズに既存タスクを引き継げるようにすることを目的としています。

環境セットアップで問題が発生した場合は、本ドキュメントのトラブルシューティングに加え、必要に応じて `docs/[作業記録].md` やリポジトリの issue／コミットログを参照してください。
